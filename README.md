## Installation

1. Type `/xlsettings` in the FFXIV chat
2. Go to **Experimental**, then **Custom Plugin Repositories**
3. Add this link:
   ```
   https://raw.githubusercontent.com/SunnysTTV/sunnysrepo/main/pluginmaster.json
   ```
4. Click **+** and **Save**
5. Open the Plugin Installer with `/xlplugins` and search for the plugin
